# 环境配置指南（Windows）

> 面向：苏致远（第一次在本机配置）
> 目标：从零配到能跑通 Customized ROI baseline 的文本定位（LSeg / CLIPSeg）与 TIC 模型
> 预计耗时：2–4 小时，绝大部分时间花在下载权重上
> 本文所有命令都在 **cmd** 里执行，工作目录默认为项目根目录

## 1. 前置检查

需要：Windows 10/11、NVIDIA 显卡、磁盘 ≥ 15 GB、能联网。

```bat
nvidia-smi
git --version
curl --version
tar --version
```

`nvidia-smi` 能看到显卡和驱动版本即可（不要求单独装 CUDA Toolkit，PyTorch 的 wheel 自带 CUDA runtime）。
`curl` / `tar` 是 Windows 10 1803 以后自带的，缺了说明系统太旧。

## 2. 建 conda 环境

Anaconda 安装包走清华镜像下载：
<https://mirrors.tuna.tsinghua.edu.cn/anaconda/archive/>

## 3. 安装 PyTorch（CUDA 版）

```bat

```

本机实测：**torch 2.14.1+cu126 / torchvision 0.29.1+cu126**。

期望输出类似 `2.14.1+cu126 True NVIDIA GeForce RTX 4060 Laptop GPU`。

## 6. 一键装依赖 + clone 三方仓库

```bat
scripts\setup.bat
```

它做两件事：

1. `pip install -U pip` + `pip install -r requirements.txt`
2. `git clone --depth 1` 三个仓库到 `third_party/`：
   - `Customizable-ROI-Based-Deep-Image-Compression`（论文官方代码）
   - `Grounded-SAM-2`（改进 1 的主方案，暂时用不到）
   - `clipseg`（改进 1 的轻量备选）

> **关键**：`setup.bat` 必须保持**纯 ASCII**。cmd.exe 默认按 GBK 解析 .bat，文件里出现中文会被当成乱码命令执行，脚本直接死在第一行（我们踩过：`'鍙儿砱:' 不是内部或外部命令`）。要加注释就用英文。

`requirements.txt` 没覆盖 LSeg / CLIPSeg 的依赖，需要补装：

```bat
python -m pip install timm transformers thop
python -m pip install git+https://github.com/openai/CLIP.git
```

各自为什么需要：

| 包 | 用途 |
|---|---|
| `timm` | LSeg 的图像骨干 `vit_large_patch16_384` |
| `transformers` | CLIPSeg（`CLIPSegForImageSegmentation`） |
| `clip` | LSeg 的文本编码器，官方代码里直接 `import clip` |
| `thop` | `eval_kodak.py` 第 36 行 `from thop import profile`，缺了直接 ImportError（虽然实际没调用） |

装完的完整版本清单见附录 A。

## 8. 下载预训练权重（4 份，约 2.7 GB）

### 8.1 OpenAI CLIP ViT-B/32 — 353,976,522 B

```bat
mkdir "%USERPROFILE%\.cache\clip"
curl -L -C - -o "%USERPROFILE%\.cache\clip\ViT-B-32.pt" https://openaipublic.azureedge.net/clip/models/40d365715913c9da98579312b702a82c18be219cc2a73407c4526f58eba950af/ViT-B-32.pt
```

注意事项（实测）：

- **这条不要挂代理**。走 7890 反而 `http=000` 连不上，直连约 200 KB/s，353 MB 需要约 30 分钟。
- 必须手工下到缓存目录。`clip.load()` 自己下载时用的是 `"wb"` 模式（覆盖写），中途断了会从头开始，所以用 `curl -C -` 续传。

### 8.5 检查下载完整性（最容易翻车的一步）

下载中断时**文件名和路径都正常，只有大小不对**，等到跑模型才报错，很难排查。所以下载完先对大小：

```bat
dir "%USERPROFILE%\.cache\clip"
dir third_party\Customizable-ROI-Based-Deep-Image-Compression\checkpoints
```

对照附录 B 的字节数，**必须精确相等**。

> 实际踩过的坑：COCO val2017 用 `curl -C - --retry 5` 下载，代理中途断开，curl 报 `end of response with ... bytes missing` 但因为是管道调用、退出码被 `tail` 吃掉了，看起来像"成功"，结果文件只有 128.9 MiB / 777.8 MiB，`zipfile` 直接 `BadZipFile`。**加 `--retry-all-errors`** 才会自动续传。

## 11. 已知坑（都是实际踩过的）

| 现象 | 原因 | 解决 |
|---|---|---|
| `'鍙儿砱:' 不是内部或外部命令` | cmd 按 GBK 读 UTF-8 的 .bat | .bat 保持纯 ASCII |
| pip 卡在 `Retrying (Retry(total=4...))` | pypi.org 直连超时 | 换清华源（第 4 节） |
| `LocalEntryNotFoundError` | huggingface.co 不通 | `set HF_ENDPOINT=https://hf-mirror.com` |
| GitHub raw 401 / 超时 | raw.githubusercontent.com 被墙 | 前面加 `https://gh-proxy.com/` 前缀 |
| `RuntimeError: expected scalar type Half but found Float` | `clip.load(device="cuda")` 返回 **fp16** 模型（clip 源码里只有 `device=="cpu"` 才 `.float()`），和 LSeg 的 fp32 特征算余弦 | 加载后 `net.clip_pretrained.float()` |
| 构造 TIC 时卡住下载 1.2 GB | `timm.create_model(..., pretrained=True)` | LSeg 的 ckpt 已含全部骨干权重，把 `pretrained` 改成 `False`（见下方代码） |
| `UnpicklingError` / `Weights only load failed` | torch ≥ 2.6 的 `torch.load` 默认 `weights_only=True` | 传 `weights_only=False` |
| bpp 明显不对 / PSNR 正常 | compressai 版本差异，见下方【重要】 | 键名映射 |
| `ModuleNotFoundError: thop` | requirements.txt 没列 | `pip install thop` |

### 【重要】compressai 版本差异 —— 会静默丢参数

论文用的是 **CompressAI 1.2.0b3**，本机装的是 **1.2.8**。两者的 `EntropyBottleneck` 参数命名不同：

| 1.2.0b3（论文 ckpt 里的键） | 1.2.8（模型里的键） |
|---|---|
| `entropy_bottleneck._matrix0` | `entropy_bottleneck.matrices.0` |
| `entropy_bottleneck._bias0` | `entropy_bottleneck.biases.0` |
| `entropy_bottleneck._factor0` | `entropy_bottleneck.factors.0` |

官方的加载方式只拷贝 key 能对上的参数：

```python
model_dict = model.state_dict()
compatible_dict = {k: v for k, v in checkpoint_dict.items() if k in model_dict}
model_dict.update(compatible_dict)
model.load_state_dict(model_dict)
```

结果就是 **`entropy_bottleneck` 的 20 个参数被静默跳过**，用的是随机初始化。PSNR 不受影响（`x_hat = g_s(y_hat)` 与熵模型无关），但 **bpp 会全错**，而且不报任何错。

解决办法：加载前先改名。

```python
def rename_entropy_keys(sd):
    """把 CompressAI 1.2.0b3 的键名映射到 1.2.8。"""
    out = {}
    for k, v in sd.items():
        if k.startswith("entropy_bottleneck._"):
            p = k.split(".")[-1]
            if p.startswith("_matrix"):
                k = "entropy_bottleneck.matrices." + p[len("_matrix"):]
            elif p.startswith("_bias"):
                k = "entropy_bottleneck.biases." + p[len("_bias"):]
            elif p.startswith("_factor"):
                k = "entropy_bottleneck.factors." + p[len("_factor"):]
        out[k] = v
    return out
```

已验证：改名后 20/20 个 `entropy_bottleneck` 键全部对上，除 `net_lseg`（从 LSeg ckpt 单独加载）外**零缺失**。

### 跳过 1.2 GB ViT-L 下载

`TIC.__init__` 内部会 `timm.create_model("vit_large_patch16_384", pretrained=True)`。
LSeg 的 ckpt 本来就包含骨干全部权重，下载纯属浪费：

```python
import timm
_orig = timm.create_model
timm.create_model = lambda *a, **k: _orig(*a, **{**k, "pretrained": False})
# 之后再 from model_tic import TIC
```

`scripts/run_lseg_mask.py` 和 `scripts/check_env.py` 里都是这么处理的。

### 官方 eval_kodak.py 的硬编码

| 位置 | 原值 | 改成 |
|---|---|---|
| `eval_kodak.py:2` | `CUDA_VISIBLE_DEVICES = "1"` | `"0"`（单卡机器） |
| `eval_kodak.py:110` | `/path/to/lseg/checkpoint/lseg_minimal_e200.ckpt` | 实际路径 |
| `eval_kodak.py:118` | `/path/to/checkpoint/best_loss.pth.tar` | 实际路径 |
| `eval_kodak.py:144` | `/path/to/dataset/` | `data\coco\val2017\`（**注意要带 val2017 这一层**） |
| `eval_kodak.py:227` | `/path/to/image/` | 输出目录 |
| `COCO_dataset.py:44` | `/path/to/val_test_select.json` | 仓库里自带，改成本地路径 |
| `COCO_dataset.py:66` | `/path/to/dataset/val2017/` | 实际路径 |

`eval_kodak.py` 里用到的 `device` 不是自己定义的，而是 `from model_tic import *` 从 `model_tic.py:34` 带过来的全局变量（固定 `"cuda"`）。单卡机器不用管，多卡才需要动 `CUDA_VISIBLE_DEVICES`。
